## 交互与资产

星球阅读使用背景路由，关闭窗口后继续原来的星图位置。原生 dialog 处理焦点、Escape、背景关闭和滚动恢复；表单提交中禁止误关闭。图片预览从缩略图位置展开，关闭后回到缩略图。卡片 / 图片动画尊重 reduced-motion。

`public/images/community/` 保存已确认的笔刷、花束和实际人物照片。`public/fonts/noto-sans-sc/` 提供本地 400/700/900 字重和 OFL 许可证。头像、打卡图、排行榜、名片、问题和学习状态来自原有数据，不使用原型假数据代替。
