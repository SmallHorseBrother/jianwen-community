# 人脉星图

入口：顶栏“人脉星图”（手机端在导航菜单中），也可从“产品”或“找伙伴”进入。线上地址：https://jwcommunity.space/network 。使用现有 React / Three.js，数据与头像随网站静态部署，无新增服务或数据库表。

名录只收录 CipherTalk 当前群成员。显示名优先群昵称，其次微信昵称；不使用私人通讯录备注。对外 ID 为散列值，不公开微信账号。成员资料来自已逐条核对的群内自我介绍，未识别介绍的成员显示现有昵称与可见发言统计。原始头像保存为 160px WebP，图片内容保持原样。

页面顶部可切换 9 个群：原创业交流群，以及学习群、健身群、健文学院 1–3 班、健身群（一）至（三）。例如学习群链接为 `https://jwcommunity.space/network?group=learning`。旧 `/network` 和未带群参数的名片链接继续指向创业交流群。切群会清除上一群的筛选和选中成员；分享地址同时保留群和成员。

群目录在 `public/data/network-groups.json`，每个群分别加载数据；原创业群仍用 `network-atlas.json`，其他群在 `public/data/network/`。不同群的昵称、介绍、发言数与互动独立，不把其他群的介绍自动搬过来。跨群重复成员复用同一头像。名录、搜索和导出包含全体当前成员；桌面星图最多展示 140 个节点、350 条线，手机最多 70 个节点、180 条线，优先选中成员及关联成员，界面明确显示当前呈现数量。

关系分为成员自述的合作、可定位消息的群内引用或提及、基于资源与需求关键词的潜在匹配、共同方向。后两类明确标注推荐，不代表真实合作。页面可搜索、筛选主题与项目阶段，切换名录，打开名片、查看自述和关系依据，复制名片链接，导出筛选后的 CSV。

## 更新数据

先让 CipherTalk 同步，随后在项目目录执行：

```powershell
node scripts/import-network-atlas.mjs
node scripts/import-network-atlas.mjs --write --avatars
node scripts/import-network-atlas.mjs --group learning --write --avatars
node --test scripts/network-atlas.test.mjs
```

默认只读检查。`--write` 更新 `public/data/network-atlas.json`，`--avatars` 补齐本地头像。已下载头像不会重复下载。数据目录自动读取本机 CipherTalk CLI 配置；解压使用现有 CipherTalk 的 fzstd。可用 `CIPHERTALK_ROOT` 指定 CipherTalk 安装目录。需要支持 `node:sqlite` 的 Node 版本。

`scripts/network-atlas.config.json` 按群维护 `reviewedIntroductionIds`；新记录使用 `message_2.db:123` 这样的分片加本地消息 ID，防止不同数据库中同号消息误配。旧创业群数字 ID 只对应 `message_2.db`。新成员介绍先核对，再加入。`collaborations` 仅添加原话明确说明的合作。只读候选检查可运行 `node scripts/review-network-introductions.mjs learning` 或追加 `--early` 检查最初的短介绍；候选不会自动发布。转发公告、玩笑模板、敏感健康描述等不直接用作名片。未收录介绍不代表成员未介绍过。

导入器按 1,000 条消息分页读取现有数据库，并按服务器消息 ID 去重，不复制聊天数据库、不一次加载整群正文。头像最多 6 个并行请求，并跨群复用。先验证数据目录；缺少成员或消息会停止导出，不用空数据覆盖。已退群者在下次导入后不再出现在名录，已下载的孤立头像文件可按 ID 清单单独审核清理。

这是同步快照，不是实时监听。部署更新后才会反映新资料。页面标注更新时间、可见记录起止时间与消息量，不能解释成完整群历史。新增粉丝群的引用和提及只公开次数与时间，不公开聊天正文；经核对的自我介绍另行展示，电话号码和微信账号在输出时隐藏。

## 部署与回退

沿用健文社区现有前端部署流程，包含新增 `public/data/network-atlas.json` 和 `public/images/network/`。历史路由回退必须支持 `/network`，与已有 `/qa` 路由一致。不要把 CipherTalk 原始数据库或 CLI 配置上传。

向现有 GitHub 仓库的 `main` 分支推送会触发自动部署，目标站点为 `https://jwcommunity.space/`。本次变更为独立页面、数据导入器与入口修改；不涉及 Supabase、身份权限或其他产品。若需回退，回退本功能提交并沿用同一发布流程。
