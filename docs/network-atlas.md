# 人脉星图

入口：首页独立的“人脉星图”大入口、顶栏（手机端在导航菜单中），也可从“产品”或“找伙伴”进入。与“找伙伴”保持独立，不合并为切换页；不改找伙伴或登录逻辑。线上地址：https://jwcommunity.space/network 。使用现有 React / Three.js，数据与头像随网站静态部署，无新增服务或数据库表。

名录只收录 CipherTalk 当前群成员。显示名优先群昵称，其次微信昵称；不使用私人通讯录备注。对外 ID 为散列值，不公开微信账号。成员资料结合已核对的自我介绍与逐人归纳的聊天画像：具体实践、问题、经历与需求分节呈现，区分“本人表达”和“综合推测”。原始头像保存为 160px WebP，图片内容保持原样。

页面顶部可切换 9 个群：原创业交流群，以及学习群、健身群、健文学院 1–3 班、健身群（一）至（三）。例如学习群链接为 `https://jwcommunity.space/network?group=learning`。旧 `/network` 和未带群参数的名片链接继续指向创业交流群。切群会清除上一群的筛选和选中成员；分享地址同时保留群和成员。

群目录在 `public/data/network-groups.json`，每个群分别加载数据；原创业群仍用 `network-atlas.json`，其他群在 `public/data/network/`。不同群的昵称、介绍、发言数与互动独立，不把其他群的介绍自动搬过来。跨群重复成员复用同一头像。名录、搜索和导出包含全体当前成员；桌面星图最多展示 140 个节点、350 条线，手机最多 70 个节点、180 条线，优先选中成员及关联成员，界面明确显示当前呈现数量。

群分类由 `scripts/network-taxonomies.mjs` 统一维护，导入器与公开快照使用同一份规则。创业群按行业与项目阶段；学习群及健文学院三班按学科、技能与学习目标；四个健身群按运动项目与训练目标。学科/运动标签结合昵称、自述和发言归纳，目标结合自述与发言中第一人称表达的意向。讨论方向不推断成职业、学历、医学诊断或训练水平。缺少依据时保留“待补充”；分类是辅助整理，不是认证事实。

具体画像不再仅由关键词生成。`scripts/network-portrait-evidence.mjs` 用三进程只读扫描各群历史，在公开快照的成员与时间范围内准确统计消息类型，再选取时间分散、内容多样的本人文字和回复供并行逐人分析。一般成员至多选30条，小马哥至多80条；必要时针对问题补读原记录。引用回复只取回复者自己的标题，引用上下文归原作者；文章标题只表示分享行为。转发段子、给他人的建议、产品服务对象不能写成本人的经历或目标；不公开敏感个人资料。

分析结果为 version 2 的 `portrait`：摘要、具体分节、标签、同群分类与明确目标。每节携带该成员的消息ID和原时间，公开页面仅展示来源时间，不发布聊天正文。发布器拒绝未分析的有效样本、跨人引用、时间不符、非法分类或私密账号；补读的额外证据会重新从原库校验归属。信息不足者保留准确消息构成，不硬写职业或能力画像；已有审核自述继续保留。旧关键词摘要被移除，不再污染目标、搜索与CSV。

关系保留成员明确自述的合作和可定位消息的群内引用/提及。创业群另提供潜在供需匹配；学习、健身群只提供共同学习方向或运动兴趣线索，不冒充已结伴。页面可搜索、筛选分类与对应目标，切换名录，查看名片、自述和关系依据，复制名片链接，导出筛选后的 CSV；非创业群不展示项目阶段。

## 更新数据

先让 CipherTalk 同步，随后在项目目录执行：

```powershell
node scripts/import-network-atlas.mjs
node scripts/import-network-atlas.mjs --write --avatars
node scripts/import-network-atlas.mjs --group learning --write --avatars
node scripts/import-network-atlas.mjs --reclassify --write
node scripts/import-network-atlas.mjs --summarize-speech --write
node scripts/network-portrait-evidence.mjs --output D:/cache/agent-tests/jianwen-portraits-20261013
node scripts/publish-network-portraits.mjs --input D:/cache/agent-tests/jianwen-portraits-20261013
node scripts/publish-network-portraits.mjs --input D:/cache/agent-tests/jianwen-portraits-20261013 --write
node --test scripts/network-atlas.test.mjs scripts/network-portraits.test.mjs
```

默认只读检查。`--write` 更新 `public/data/network-atlas.json`，`--avatars` 补齐本地头像。已下载头像不会重复下载。数据目录自动读取本机 CipherTalk CLI 配置；解压使用现有 CipherTalk 的 fzstd。可用 `CIPHERTALK_ROOT` 指定 CipherTalk 安装目录。需要支持 `node:sqlite` 的 Node 版本。

`--reclassify` 仅用已有公开快照重新归类，不读取聊天数据库、不下载头像，不改变成员、原话、真实互动或源数据更新时间。也支持 `--group`；省略 `--write` 为只读预览。

`--summarize-speech` 是旧规则归纳的兼容入口，已有具体画像不会被覆盖。正常导入和重新分类也保留具体画像及其原来源截止时间；新消息同步不等于画像已重新分析。

证据生成后，需实际逐人分析 `evidence/<group>.jsonl`，输出 `portraits/<group>.json`；不能只生成证据就当作完成。本文命令不自行调用外部付费模型。画像发布器默认只读预检，可用 `--group learning`；加 `--write` 时先验证全部所选群，再更新对应公开JSON与推测关系，保留真实关系、成员、自述、头像和消息统计。原始证据、分析工作文件只留D盘任务目录，不提交仓库。

`scripts/network-atlas.config.json` 按群维护 `reviewedIntroductionIds`；新记录使用 `message_2.db:123` 这样的分片加本地消息 ID，防止不同数据库中同号消息误配。旧创业群数字 ID 只对应 `message_2.db`。新成员介绍先核对，再加入。`collaborations` 仅添加原话明确说明的合作。只读候选检查可运行 `node scripts/review-network-introductions.mjs learning` 或追加 `--early` 检查最初的短介绍；候选不会自动发布。转发公告、玩笑模板、敏感健康描述等不直接用作名片。未收录介绍不代表成员未介绍过。

导入器按 1,000 条消息分页读取现有数据库，并按服务器消息 ID 去重，不复制聊天数据库、不一次加载整群正文。头像最多 6 个并行请求，并跨群复用。先验证数据目录；缺少成员或消息会停止导出，不用空数据覆盖。已退群者在下次导入后不再出现在名录，已下载的孤立头像文件可按 ID 清单单独审核清理。

这是同步快照，不是实时监听。部署更新后才会反映新资料。页面标注更新时间、可见记录起止时间与消息量，不能解释成完整群历史。新增粉丝群的引用和提及只公开次数与时间，不公开聊天正文；经核对的自我介绍另行展示，电话号码和微信账号在输出时隐藏。

## 部署与回退

沿用健文社区现有前端部署流程，包含新增 `public/data/network-atlas.json` 和 `public/images/network/`。历史路由回退必须支持 `/network`，与已有 `/qa` 路由一致。不要把 CipherTalk 原始数据库或 CLI 配置上传。

向现有 GitHub 仓库的 `main` 分支推送会触发自动部署，目标站点为 `https://jwcommunity.space/`。本次变更为独立页面、数据导入器与入口修改；不涉及 Supabase、身份权限或其他产品。若需回退，回退本功能提交并沿用同一发布流程。
